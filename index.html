Projet 01 · Réseaux

Lab réseau Cisco

Conception et configuration d'une infrastructure réseau segmentée avec VLANs et routage inter-VLAN sur équipements Cisco.

Contexte

Projet réalisé dans le cadre du BTS CIEL. L'objectif était de simuler une infrastructure réseau d'entreprise réaliste avec plusieurs départements isolés en VLANs communicant via un routeur central.

Informations
Outil
Cisco Packet Tracer
Équipements
Switch 2960, Router 2911
Protocole
802.1Q, OSPF
VLANs
4 segments
Déroulement
1
Conception de la topologie
Définition du plan d'adressage IP, répartition des VLANs par département (RH, IT, Direction, Serveurs).
2
Configuration des switches
Création des VLANs, affectation des ports en mode access et trunk, configuration du STP.
3
Routage inter-VLAN
Configuration du routeur en Router-on-a-stick avec sous-interfaces 802.1Q, vérification de la connectivité entre VLANs.
4
Tests & validation
Tests de connectivité ping, vérification des tables de routage, simulation de pannes et dépannage.
Technologies utilisées
VLAN 802.1Q Trunk / Access Router-on-a-stick DHCP Cisco IOS Packet Tracer

Projet 03 · Systèmes

Déploiement & Gestion de flotte

Automatisation du déploiement Windows en entreprise via MDT et supervision centralisée de la flotte via une solution MDM.

Contexte

Projet visant à industrialiser le déploiement de postes Windows dans un contexte d'entreprise — réduction du temps d'installation, standardisation des images système et gestion centralisée de la flotte via MDM.

Informations
Déploiement
MDT + WDS
OS déployé
Windows 10/11
MDM
Microsoft Intune
Cloud
Azure AD
Déroulement
1
Mise en place MDT
Installation de Microsoft Deployment Toolkit, création du partage de déploiement, import des images Windows.
2
Construction de la séquence de tâches
Intégration des drivers, applications silencieuses (Office, antivirus), paramétrage des étapes de personnalisation.
3
Démarrage réseau WDS
Configuration du serveur WDS pour le boot PXE, permettant le déploiement sans média physique sur les postes.
4
Enrollment MDM
Inscription automatique des postes dans Microsoft Intune via Azure AD Join, déploiement des politiques de sécurité et applications.
Technologies utilisées
MDT WDS / PXE Windows 10/11 Microsoft Intune Azure AD PowerShell SCCM (notions)
